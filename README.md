# Claude Proxy Guard

**Для службы информационной безопасности:** [архитектура, права, сеть, хранение данных, ограничения и результаты проверок](README-ИБ.md).

Независимое приложение для запуска собственной локальной копии установленного Claude Desktop с проверкой выходного IP, контролем маршрута и просмотром доступного веб-трафика. Не связано с Anthropic. Claude и учётная запись в комплект не входят.

## Платформы и возможности

- **Windows 10/11 x64 — 0.6.15.** Закрыты обходы JavaScript-проверок прокси и диагностического IPC; исправление запуска `Guard cannot protect connect` сохранено. Доступны установщик `Setup.exe` и portable ZIP. Electron 44.9.2; локальный шлюз, WFP для исполняемых файлов копии Claude, Windows Job Object. Claude Code, native Git HTTPS и PowerShell работают через предусмотренный AppContainer/CodeGate. Code закреплён на Desktop 3.1623.0 и CLI 2.1.304; Git Bash и Git SSH в этом режиме недоступны.
- **macOS 13+ — 0.3.8, universal arm64 + x86_64.** Один DMG или ZIP для Apple Silicon и Intel. SwiftUI, локальный шлюз, мониторинг IP и PF-барьер; архитектура и ограничения описаны в [SECURITY.md](SECURITY.md). Постоянное закрепление IP добавлено на обеих платформах.
- Linux и отдельная Windows ARM64-сборка не подготовлены. macOS Intel-компонент можно собрать и проверить как часть universal-бандла; исполнение на Intel проверяется отдельно.

Доступны текущая сеть/VPN и SOCKS5, закрепление IP, пауза при временной ошибке проверки, завершение сессии при подтверждённой смене IP, профиль страницы, локальные журналы и экспорт доступного HTTP/SSE/WebSocket-трафика. Проверки периодические: мгновенный сетевой kill switch и абсолютное отсутствие утечек не заявляются.

## Постоянное закрепление IP

Первый адрес сохраняется только после успешной проверки страны, общего внешнего IP и выходов к `claude.ai` и `api.anthropic.com`. Все эти проверки должны подтвердить один IP. Остановка, выход, обновление и перезапуск Guard его не меняют. При другом адресе верните прежний маршрут или осознанно сбросьте закрепление.

В разделе «Постоянный IP» виден разрешённый адрес. Для смены остановите сессию и нажмите «Сбросить закрепление…»: откроется предупреждение с отменой по умолчанию. После заблокированной сессии дополнительно перезапустите Guard. Сброс не удаляет профиль Claude; следующий полностью проверенный IP станет новым закреплённым адресом.

Память хранится отдельно от профиля Claude: Windows — `%APPDATA%\Claude Proxy Guard\Guard\ip-memory.json`, macOS — `~/Library/Application Support/ClaudeProxyGuard/ip-memory.json`. Это небольшой локальный JSON без паролей и cookies. Ошибка чтения, повреждение или невозможность записи закрывают доступ; некорректный файл не заменяется новым адресом автоматически.

Для VPN выберите один сервер со стабильным выходом. Глобальный режим/TUN настраивается в самом VPN-клиенте: Guard ограничивает свою копию Claude, а не весь компьютер. Проверки IP периодические и не дают гарантии отсутствия удалённой смены адреса между проверками или решения сервиса об аккаунте.

## Установка и первый запуск

Готовые версии и их фактический статус проверок — в [GitHub Releases](https://github.com/JFT-git/gate-claude/releases). Предварительная сборка не означает проверку на всех ОС.

### Windows

1. Установите официальный Claude Desktop отдельно.
2. Запустите `ClaudeProxyGuard-Windows-0.6.14-x64-Setup.exe` для установки текущему пользователю либо полностью распакуйте portable ZIP в локальную папку. Не переносите один EXE: рядом нужны Electron, native-помощники и комплекты инструментов.
3. Запустите `Claude Proxy Guard.exe` обычным способом. Выберите текущую сеть/VPN либо SOCKS5. Claude ищется по установленным пакетам, в том числе WindowsApps; менять права WindowsApps не нужно.
4. Нажмите **«Запустить»**, подтвердите штатное окно Windows для NetworkFence и дождитесь фактической проверки профиля.
5. Для Code включите соответствующий пункт. Постоянная рабочая папка открывается кнопкой в интерфейсе; её файлы сохраняются после выхода.

**Постоянная служба пока не реализована.** NetworkFence — повышенный брокер отдельной сессии, а не служба Windows. Новый запуск защищённой сессии по-прежнему может запросить UAC. Интерфейс службы показывает отсутствие API и не имитирует установку. [Контракт будущей интеграции](docs/service-integration.md).

### macOS

Ссылки входа `claude://` принимаются Guard и передаются в защищённую копию; если macOS спрашивает приложение по умолчанию, выберите Guard.

Откройте DMG и перенесите `.app` в Applications либо в свою папку Applications; ZIP содержит такой же переносимый бандл. Не запускайте приложение как root. Выберите установленный `Claude.app`, маршрут и нажмите «Запустить». Настройки языка и часового пояса применяются к копии Claude, а не к macOS. Подробнее — [ограничения безопасности](SECURITY.md).

## Portable, обновление и удаление

Portable означает запуск из распакованной папки, **не** хранение всех данных рядом с EXE и **не** освобождение от UAC. Профиль, рабочие файлы и настройки находятся в каталоге пользователя. Даже будущая portable-сборка потребует установки системной службы, если выбранные функции будут от неё зависеть; текущая сборка такой службы не устанавливает.

Для обновления остановите сессию, закройте Guard и замените приложение целиком проверенной сборкой той же платформы. Сохраните профиль и Workspace. Не смешивайте файлы разных версий. Встроенного автоматического обновления Guard нет.

Для обычного удаления сначала остановите Claude через Guard и закройте приложение, затем удалите папку программы / `.app` или используйте подготовленный пользовательский установщик. Профиль и рабочие документы автоматически не удаляются. Пошаговое **полное удаление**, регистрация ссылок и восстановление сетевых ограничений после аварии описаны в [инструкции эксплуатации](docs/operations.md).

## Диагностика

Интерфейс отдельно показывает сессию Claude, отсутствие/состояние API службы, выполнение текущего действия и его результат. «Перезапустить» перезапускает Guard и завершает его сессию; это не автоматический повторный вход в Claude. Во время незавершённого UAC повторное повышение не создаётся.

Откройте **«Журнал»**. Если окно Windows не появляется, запишите версию Guard, этап и фиксированный код ошибки, проверьте «Журнал защиты» Windows. Ошибка Code после обновления Claude может означать неподдерживаемый закреплённый SDK. Не снимайте сетевую защиту и не меняйте ACL WindowsApps для обхода ошибки.

Не публикуйте тела запросов, профили, magic link, пароли и сырые журналы. Экспорт трафика может содержать переписку и неизвестные секреты даже после маскирования. [Где находятся данные и что приложить к обращению](docs/operations.md).

## Безопасность и сведения для ИБ

[README для службы ИБ](https://github.com/JFT-git/gate-claude/blob/main/README-%D0%98%D0%91.md) находится в корне основной ветки репозитория.

[SECURITY.md](SECURITY.md) описывает архитектуру, границы привилегий, службу и UAC, сетевые подключения, порты, хранение данных, телеметрию, происхождение и подписи сборок, удаление и сообщение об уязвимостях. Сертификаты соответствия и прохождение проверок ИБ не заявляются.

Исходники распространяются по MIT. Windows-сборки не имеют настроенной подписи издателя. macOS-бандл подписывается ad-hoc для проверки целостности; это **не Developer ID и не нотариализация**. SHA-256 связывает файл с опубликованной контрольной суммой, но сам по себе не доказывает личность издателя.
