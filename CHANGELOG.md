# Изменения

## Windows 0.8.1 / macOS 0.5.1 — 2026-11-05

- Исправлено наложение заголовка главного окна Claude Code: возвращена системная рамка `default` и удалено кастомное смещение нативных кнопок. Патч применяется к фактическому `.vite/build` модулю окна; остальные окна не затронуты.
- macOS: очистка после аварии Guard корректно удаляет crash-запись, если замороженный процесс Claude уже завершился.

## Windows 0.8.0 / macOS 0.5.0 — 2026-11-05

- Добавлена фактическая заморозка дерева Claude на 20 секунд с продолжением при возврате разрешённого IP. После дедлайна — graceful close до 5 секунд и принудительное завершение. Повторные события не продлевают ожидание.
- Добавлены новый нативный UI в спокойном стиле: hero-статус, страна/IP, состояния процессов, countdown, история и настройки. Светлая/тёмная тема, 200% zoom, клавиатурная доступность.
- Windows стабилизирует снимки потоков через GuardHost с проверкой Job PID list и PID/TID/creation-time; macOS использует `SIGSTOP`/`SIGCONT` по проверенной PGID. При восстановлении сохраняются тот же PID и профиль, но in-flight потоки не восстанавливаются.
- RU-маршрут, потеря WFP/PF, смена системного прокси и diagnostic/security failures остаются немедленными `block` без grace window. Аварийное завершение не оставляет процессы замороженными бессрочно.
- Исправлено завершение Claude при быстром закрытии вспомогательного окна во время его инициализации: ожидаемый `target closed` изолирован от основной сессии.
- Исправлены большие загрузки Claude Code: корректные `keepAlive`/TLS close, отсутствие преждевременного destroy и лимит только для CONNECT-заголовка, а не первых TLS-байтов.

## Windows 0.7.1 / macOS 0.4.1 — 2026-11-03

- Claude Code обновлён до официального Desktop 1.44121.2: новые SDK/main/sessions/scratch hashes и адаптер HostCLIRunner через защищённый broker. Закреплённый CLI 2.1.304 сохраняется.
- Исправлена несовместимость NSIS с прежним Inno-каталогом `%LOCALAPPDATA%\Programs\Claude Proxy Guard`.
- Добавлены регрессионные тесты новых anchors, отказов неизвестных файлов и install path. Реальный Windows smoke и запуск Claude Code проверяются отдельно.

## Windows 0.7.0 / macOS 0.4.0 — в разработке

- Добавлена проверка стабильных GitHub Releases при запуске и раз в сутки, фоновая загрузка и отображение прогресса. Перед остановкой сессии, установкой и перезапуском требуется подтверждение.
- Windows использует per-user NSIS, blockmap-дельты и автоматический fallback на полный пакет. Portable не изменяется на месте и обновляется вручную.
- macOS использует Sparkle 2 и подписанный полный universal ZIP. Метаданные и пакеты обновлений подписываются отдельными Ed25519/EdDSA-ключами; приватные ключи не входят в репозиторий и артефакты.
- Profile, CodeState, Workspace, настройки, diagnostics и `ip-memory.json` сохраняются. После перезапуска Guard не возобновляет Claude автоматически.
- Для первого перехода на updater-capable версию нужна одна ручная установка. До публикации требуется installed A→B проверка на настоящей Windows.

## Windows 0.6.16 / macOS 0.3.9 — 2026-11-02

- Диагностический IPC на Windows отклоняет malformed JSON и некорректные параметры аутентификации без необработанного исключения; после отклонения постороннего соединения штатное подключение продолжает работать.
- Общий загрузчик разрешает только настоящие loopback IP без DNS и передаёт Electron однократно проверенный неизменяемый snapshot прокси. Закрыты обходы через изменяемые getters, унаследованный PAC и coercion.
- Windows-защита не передаёт native API объекты с вызываемым преобразованием типов и отклоняет управляющие символы в аргументах командной строки.
- Исправлен список исходников NetworkFence в Windows CI: добавлены `CodeNetworkFence.cs` и `CodeFenceSession.cs`.
- Добавлены регрессионные IPC, DNS, proxy и native-boundary тесты. Native Windows, UAC/WFP и установка/удаление на Windows этим релизом не проверялись.

## Windows 0.6.15 / macOS 0.3.8 — 2026-10-30

- Постоянная память одного внешнего IP: первый полностью проверенный адрес сохраняется в `ip-memory.json` и действует после остановки, обновления и перезапуска.
- Общий выход и маршруты `claude.ai` / `api.anthropic.com` должны совпадать; независимые выходы и другая семья адреса больше не разрешаются как отдельные закрепления.
- В интерфейсе обеих платформ виден сохранённый IP; сброс требует остановки и отдельного предупреждения с отменой по умолчанию. Профиль Claude сохраняется.
- Повреждённая память или ошибка записи не разрешают запуск. Добавлены проверки повторного запуска, отмены сброса, конкурентных действий и отказов хранилища.


## Windows 0.6.14 — защита параметров прокси и IPC

- Закрыт обход `session.setProxy` через изменяемые getters: параметры читаются один раз, проверяются и передаются Electron отдельным неизменяемым объектом без прототипа. Адрес разрешённого прокси закрепляется при установке защиты.
- Закрыт обход проверки диагностического IPC через подмену `path`: Node получает только проверенную строку своего канала и необязательный callback. Исходный объект параметров не передаётся дальше.
- Добавлены регрессионные тесты изменяемых и унаследованных свойств, реальные IPC-соединения и отдельная проверка четырёх полей прокси на настоящем Electron API (`npm run test:runtime-proxy`).
- WFP, Job Object, AppContainer, macOS-код и пользовательские Profile/Workspace не изменены. Полная проверка Windows-native изоляции остаётся отдельной задачей.

## Windows 0.6.13 — исправление запуска

- Исправлен сбой `Guard cannot protect connect`: Windows-загрузчик больше не запускает общий сетевой перехват поверх уже установленной Windows-защиты.
- Строгие Windows-ограничения Node-сети, диагностического канала, прокси, WebRTC и запуска процессов сохранены. Общий загрузчик macOS не изменён.
- Добавлены проверки полного сгенерированного загрузчика для Chat и Code, включая запрет прямых соединений и изменения прокси. Изменение загрузчика автоматически создаёт новую копию Runtime, сохраняя существующий Profile.

## Windows 0.6.9 / macOS 0.3.4 — UX и упаковка

- Единая группа «Запустить / Остановить / Перезапустить», согласованные векторные иконки и основной акцент по состоянию.
- Windows: индикатор выполнения, защита от повторных действий, отдельный результат операции, ошибки с переходом в журнал, клавиатурные вкладки, адаптация к узкому окну и масштабу 200%.
- macOS: равные кнопки в статусной карточке, обратная связь о последнем действии, быстрый доступ к журналу и нативные сочетания клавиш.
- Честный интерфейс отсутствующего API постоянной службы; контракт шести состояний и действий с тестами. Служба и снятие повторного UAC не реализованы. Текущий elevated broker сессии сохранён.
- Переработаны README, сведения для ИБ, установка, portable, обновление, полное удаление и диагностика. Различия Windows/macOS и отсутствие подписей издателя обозначены явно.
- Подготовлены Windows per-user Inno Setup и portable ZIP, macOS universal ZIP/DMG, SHA-256/manifest и неактивные workflow-шаблоны. Готовность конкретного файла и проверки — только в release notes/validation данного релиза.
- Движок, WFP, Job, AppContainer/CodeGate, IP-политика и привилегированные операции не изменены относительно baseline `6d5ede2`.
