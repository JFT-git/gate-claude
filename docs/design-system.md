# Дизайн-система и проверка интерфейса

## Основа

Дизайн проработан с Claude Code CLI, модель `claude-opus-5-5`: review опубликованных HTML/CSS baseline `6d5ede249b9992ae8222839fbd5b704d579275fb` и требований пользователя. CLI работал без инструментов, MCP, изменений файлов и доступа к профилю. Реализация и проверка рекомендаций выполнены в этом репозитории. Непубличные исходники, OAuth-коды, журналы и настройки в дизайн-запрос не передавались.

Обновление для заморозки дополнительно создано через OpenRouter `anthropic/claude-sonnet-5.5`: hero-статус, состояния процессов, countdown, история и настройки. Макет не является production-кодом и адаптируется к текущей модели Guard. Приватный ключ не входит в исходники или артефакты.

Стек сохранён: Electron HTML/CSS/JavaScript на Windows, SwiftUI на macOS. Растровые макеты, внешние шрифты и CDN не нужны. Windows использует локальный SVG sprite; macOS — SF Symbols. Иконки дополняют подписи, а не заменяют их.

## Визуальный язык

- Спокойный нативный стиль: системный шрифт, нейтральные поверхности, 1px borders, сетка 4/8px. Никаких градиентов, стекла, теней и декоративных эффектов. Одна главная акцентная кнопка, остальные нейтральные.
- Структура: hero-статус, страна/IP, защищаемые Claude и Claude Code, основные действия, countdown, история, обновление и настройки. Последние 5 событий, остальное через «Вся история». Вторичные элементы сворачиваются.
- Светлая и тёмная темы имеют отдельные контрастные токены и следуют системной по умолчанию. Статус обозначается иконкой и текстом, цвет не единственный носитель информации.
- Freeze: `00:20` → `00:00` с tabular numerals и линейным прогрессом, затем graceful close 5 секунд. Live region сообщает только пороги и смену состояния, не каждую секунду.
- 320–420px без горизонтального скролла, 200% zoom, кнопки минимум 44px, видимый focus ring, reduced motion и forced colors. Windows и SwiftUI повторяют одни размеры, порядок и состояния нативными контролами.

## Компоненты и поведение

- Нейтральные светлые и тёмные поверхности, мятный акцент основного действия, отдельный цвет ошибки. Токены находятся в `Windows/src/ui/style.css`; macOS-кнопки — в `Source/DesignSystem.swift`.
- «Запустить», «Остановить», «Перезапустить» имеют одинаковые размеры и одну акцентную кнопку. В широком окне Windows действия расположены горизонтально; при узком viewport и 200% zoom они переносятся вертикально без наложений и потери подписей. Минимальная высота — 46 px на Windows и 44 pt на macOS.
- Основное действие зависит от подтверждённого состояния: запуск в idle, остановка при активности, перезапуск после блокировки. После IP-блокировки обычный запуск не разрешается. «Перезапустить» означает полный перезапуск Guard, с закрытием его сессии и повторным вводом пароля.
- Нажатие немедленно блокирует повтор той же операции. Пока подготовка запуска ещё не прислала событие состояния, остановка уже доступна. Во время незавершённого UAC перезапуск запрещён существующим контроллером и интерфейсом.
- Во время операции показаны текст этапа и индикатор. Результат и время последней операции доступны отдельно. Ошибка не исчезает сама; журнал открывается рядом с ней.
- macOS запускается как accessory с template-значком в меню-баре. Открытие окна включает regular activation, закрытие или скрытие возвращает accessory и не останавливает сессию. Меню содержит состояние сессии, открытие окна, обновления и явный выход через существующий shutdown flow; автозапуск при входе не добавляется.
- Служба показывается отдельно от сессии Claude. Шесть состояний и действия принимаются только из authoritative native status. `sessionRoutingSupported:true` разрешено лишь для running compatible API; только этот статус разрешает serviceLaunch без per-session UAC. Ошибка не заменяется выдуманным успешным состоянием.

## Доступность

Windows: семантические label/fieldset, видимый `:focus-visible`, ссылка пропуска к управлению, status/alert/live region, ARIA tabs и стрелки/Home/End, нативные disabled-кнопки, текстовое объяснение их доступности. Цвет не единственный носитель состояния. Поддерживаются reduced motion и forced colors; общий контент прокручивается при уменьшении окна и увеличении масштаба.

macOS: нативные контролы SwiftUI и названия кнопок, Return для запуска, Cmd+. для остановки, Cmd+L для журнала. Минимальное окно и ScrollView сохраняют доступ к настройкам. VoiceOver и высокий контраст требуют отдельной ручной проверки; наличие семантики не означает сертификацию доступности.

## Проверки

`node --test Windows/test/service-integration.test.cjs` проверяет контракт и отсутствие ложного успеха, readback состояния, блокировку дублей, безопасные ошибки и доступность управления.

`cd Windows && npx electron scripts/ui-smoke.cjs` запускает настоящий renderer с тестовым IPC и временным профилем: окно, равные кнопки, ошибку, повторные нажатия, остановку, состояния, клавиатурные вкладки и масштаб 200%. Сеть fixture запрещена. Скриншоты и JSON пишутся в `GATE_UI_TEST_OUT` либо временный каталог. Это проверка UI, не установленной службы, WFP или реального Claude.

Состояния службы в этом harness — явно тестовые данные и не доказывают наличие running service. Production использует `NativeServiceBackend`. UI-smoke не проверяет Windows-native UAC/SCM, реальный Claude, VoiceOver/Narrator или Intel runtime; native lifecycle проверяется отдельными service/probe tests.
