# Claude Proxy Guard для Windows · 0.6.13

Независимое приложение для Windows 10/11 x64. Требует отдельно установленного Claude Desktop. Для Claude Code поддерживается закреплённый Desktop 3.1623.0 и CLI 2.1.304. ARM64, Git Bash и Git SSH не заявлены.

Запустите `ClaudeProxyGuard-Windows-0.6.13-x64-Setup.exe` для установки текущему пользователю или полностью распакуйте portable ZIP и запустите `Claude Proxy Guard.exe`. Нужна вся папка с Electron, native-помощниками и CodeTools. Установщик размещает эти же файлы в `%LOCALAPPDATA%\Programs\Claude Proxy Guard`.

Выберите сеть/VPN или SOCKS5, нажмите «Запустить», подтвердите запрос Windows для NetworkFence и дождитесь фактической проверки Claude. Guard ищет Claude в установленных пакетах WindowsApps; менять ACL WindowsApps не нужно. Code использует постоянную `Guard\CodeState\Workspace`, если проект не выбран. Рабочие файлы сохраняются после выхода.

NetworkFence — повышенный брокер сессии, **не постоянная служба**. API установки службы отсутствует; интерфейс сообщает это явно. Новые сессии по-прежнему требуют предусмотренного UAC. Portable не отменяет эти права. Установщик не устанавливает службу и не снимает запросы движка.

В 0.6.13 исправлен сбой `Guard cannot protect connect`: строгая Windows-защита больше не конфликтует с общим загрузчиком. Native WFP/Job/AppContainer и правила IP не менялись. Подтверждённая смена закреплённого IP закрывает сессию, временная ошибка оставляет трафик на паузе. Проверка периодическая; мгновенное отсутствие всех возможных утечек не обещается.

«Перезапустить» заново открывает Guard, закрывает его сессию и требует повторного ввода пароля прокси. После блокировки используется именно полный перезапуск. Перед обновлением/удалением штатно остановите сессию и закройте Guard; заменяйте весь комплект. Профиль и Workspace хранятся в `%APPDATA%\Claude Proxy Guard\Guard` и не удаляются автоматически.

Журнал показывает этап и фиксированный код ошибки. Экспорт трафика может содержать переписку и секреты: не публикуйте его без проверки. Пароль прокси хранится в памяти; профиль Claude содержит собственные токены и cookies.

Комплект содержит `Documentation` с README, сведениями для ИБ, диагностикой и полным удалением.
