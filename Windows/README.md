# Claude Proxy Guard для Windows · 0.8.0

Независимое приложение для Windows 10/11 x64. Требует отдельно установленного Claude Desktop. Для Claude Code поддерживается закреплённый Desktop 1.44121.2 и CLI 2.1.304. ARM64, Git Bash и Git SSH не заявлены.

Запустите `ClaudeProxyGuard-Windows-0.8.0-x64-Setup.exe` для установки текущему пользователю или полностью распакуйте portable ZIP и запустите `Claude Proxy Guard.exe`. Нужна вся папка с Electron, native-помощниками и CodeTools. Установщик размещает эти же файлы в `%LOCALAPPDATA%\Programs\Claude Proxy Guard`.

Выберите сеть/VPN или SOCKS5, нажмите «Запустить», подтвердите запрос Windows для NetworkFence и дождитесь фактической проверки Claude. Guard ищет Claude в установленных пакетах WindowsApps; менять ACL WindowsApps не нужно. Code использует постоянную `Guard\CodeState\Workspace`, если проект не выбран. Рабочие файлы сохраняются после выхода.

NetworkFence — повышенный брокер сессии, **не постоянная служба**. API установки службы отсутствует; интерфейс сообщает это явно. Новые сессии по-прежнему требуют предусмотренного UAC. Portable не отменяет эти права. Установщик не устанавливает службу и не снимает запросы движка.

В 0.8.0 добавлена фактическая заморозка Claude на 20 секунд с продолжением при возврате разрешённого IP. При восстановлении сохраняются тот же PID и профиль; открытые потоки не восстанавливаются. После дедлайна выполняется graceful close до 5 секунд и принудительное завершение. Добавлены новый нативный UI, countdown и обновлённая история. Автообновление из GitHub Releases подписывается Ed25519, NSIS поддерживает дельта-загрузку с full-package fallback. Прежние сетевые ограничения и правила IP сохранены; мгновенное отсутствие всех возможных утечек не обещается.

«Перезапустить» заново открывает Guard, закрывает его сессию и требует повторного ввода пароля прокси. После блокировки используется именно полный перезапуск. При обновлении Guard дождитесь завершения shutdown и нового запуска; Claude автоматически не стартует. Профиль, CodeState и Workspace хранятся в `%APPDATA%\Claude Proxy Guard\Guard` и не удаляются автоматически. Перед удалением штатно остановите сессию и закройте Guard.

Журнал показывает этап и фиксированный код ошибки. Экспорт трафика может содержать переписку и секреты: не публикуйте его без проверки. Пароль прокси хранится в памяти; профиль Claude содержит собственные токены и cookies.

Комплект содержит `Documentation` с README, сведениями для ИБ, диагностикой и полным удалением. Онлайн: [руководство](https://github.com/JFT-git/gate-claude/blob/main/README.md), [безопасность](https://github.com/JFT-git/gate-claude/blob/main/SECURITY.md), [релизы и реальные статусы проверок](https://github.com/JFT-git/gate-claude/releases).

Сборка не подписана Authenticode. Update metadata подписывается отдельным Ed25519-ключом; это не подпись издателя Windows. Сверяйте SHA-256 и исходный commit из релиза. Приложение не связано с Anthropic и не имеет заявленных сертификатов ИБ.

Постоянный IP сохраняется в `Guard/ip-memory.json` в каталоге данных приложения. Другой адрес, включая отдельный выход к Claude, не принимается после перезапуска. Сброс доступен только после остановки сессии и подтверждения предупреждения; отмена сохраняет закрепление. Повреждённая память и ошибка записи блокируют запуск.
