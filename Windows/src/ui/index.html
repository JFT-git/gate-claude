Guard использует собственную копию и отдельный профиль Claude. Закрытие Guard завершает его копию Claude. Оригинальные файлы Claude, язык и часовой пояс Windows не меняются.
Границы защиты и привилегий

Windows устанавливает WFP-ограничения для проверенных EXE частной копии и запускает runtime через Job Object. Это ограничение Chat по путям EXE. Claude Code использует отдельные AppContainer и CodeGate; эти режимы не являются полной изоляцией компьютера или системных служб. Текущий NetworkFence — брокер сессии, не постоянная служба.

Проверки ipwho.is, ipify и служебных адресов claude.ai / api.anthropic.com получают внешний IP без данных чата. Проверка периодическая: между изменением удалённого IP и его обнаружением есть интервал. При ошибке проверки трафик приостанавливается до подтверждения прежнего IP; подтверждённая смена закреплённого адреса закрывает сессию.

Неизвестные секреты могут остаться в данных трафика. Guard не устанавливает сертификаты MITM и не отключает TLS-проверку. Для локальной копии изменяется ASAR; подпись Anthropic не удостоверяет эту копию. Приложение независимо от Anthropic.
